# THE CATEGORY IS REQUIRED. An entry keyed only by test would exempt that test from every
# detector at once — which is exactly what happened: a `failure-masking` exemption for
# test_coexistence_under_simulated_cap silently granted it a `no-assertion` pass too.
#
# A REASON IS REQUIRED. An entry is a deliberate, reviewable decision — not a parking space.
# Prefer fixing the test. Never add an entry to restore a green run.
#
# TWO KINDS OF ENTRY, and the difference is load-bearing:
#
#   ACCEPTED — the pattern is correct here, and the reason says why. No prefix.
#   BACKLOG  — the finding is real and is DEFERRED WORK. The reason starts with `BACKLOG`,
#              and the auditor counts and prints these separately on every single run:
#
#                  N finding(s) are DEFERRED WORK, not accepted patterns.
#
#              (N is whatever the run reports — it was written here as a literal "166",
#              which was already 164 by the time anyone re-ran it. A count copied into a
#              comment is a measurement that rots; read it off the auditor.)
#
#              so a green gate can never be mistaken for a clean tree. This is what let the
#              gate be installed (pre-commit + CI) in the same change that added seven new
#              detectors, without weakening one assertion to get there.
#
# The auditor FAILS on a stale entry — one whose finding no longer exists. So this file can
# only shrink: fix a test, delete its line. An exemption nobody can forget to remove.

# the function under test returns `None` and mutates nothing this process can read: what

#

#     idempotency key, the exact lockout bucket. Asserting the (stubbed) response instead
#     would assert the stub.
#
# Each was read individually. Where a return value or observable did exist and was being
# ignored, the test was repaired rather than listed here.

# block contains the CALL SETUP too, so a renamed keyword argument, a fixture that stopped
# supplying an attribute, or an unrelated DB error all satisfy it and read as the refusal the
# test is named for. Four of these follow up with `assert getattr(exc.value, "status_code",

# the exception was an HTTPException at all. The fix in every case is to name the type
# (`pytest.raises(HTTPException)`) and assert `exc.value.status_code` directly, which also
# deletes the `# noqa: B017`. Deferred: all six live in files outside the change that added

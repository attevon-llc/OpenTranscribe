# Moved — see [OIDC_SETUP.md](OIDC_SETUP.md)

This guide was renamed when OpenTranscribe's OIDC support stopped being named for one
vendor. It covers Keycloak exactly as before, plus every other conforming OpenID
Connect provider.

Nothing you configured needs to change: the `KEYCLOAK_*` environment-variable names
keep working permanently, and the database config keys were migrated automatically.
